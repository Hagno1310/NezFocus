## 0. Thay đổi toàn cục

- **Bỏ "Guild", chỉ dùng "Server" ở mọi nơi** (Q40): văn bản SRS, schema (`guilds` → `servers`, `guild_id` → `server_id`, `user_guild_settings` → `user_server_settings`, `guild_bans`, `guild_study_stats`…), quyền (`MANAGE_GUILD` → `MANAGE_SERVER`), sự kiện Gateway (`GUILD_CREATE`, `GUILD_MEMBER_ADD`, `GUILD_DELETE`… → `SERVER_*`), REST (`/guilds` → `/servers`), Mục 1.3 (bỏ dòng "Guild là tên kỹ thuật").
- Thay thuật ngữ theo glossary: "guild học tập" → **Server ưu tiên**; "người khởi tạo"/`controller_id` → **Host**; "Solo Focus Timer" (khi nói khái niệm) → **Solo Session**; "Study Digest" → **Việc cần làm**; "Người dùng đã xóa" → **"Tài khoản đã bị xóa"**.
- Persona **Unverified User** bị bỏ khỏi Mục 2.2.1.

## 1. Sơ đồ cần thêm

Thêm vào Mục 1.3 (ngay sau dòng định nghĩa Focus Session) và đầu Mục 4.9:

```
                Focus Session  (tên chung, không tồn tại riêng)
                 ┌──────┴──────┐
          Room Session      Solo Session
          (đồng hồ chung     (đồng hồ riêng
           của một phòng)     của một người)
```

Kèm hai câu giải thích:
- Focus Session là tên chung (Q46). Mọi Focus Session là Room Session hoặc Solo Session. Luật dùng chung (cấu hình chu kỳ, Phase, pause/resume/skip, cách tính phút, mỗi user tối đa 1 Focus Session cùng lúc) gắn với Focus Session; luật khác nhau gắn với từng loại.
- Room Session **chỉ tồn tại sau khi bấm Start**. Trước Start và sau Stop, phòng chỉ là voice channel không có Focus.

Thêm bảng luật Phase (focus / short break / long break; Room Session vs Solo Session) vào Mục 4.9, như mục "Phase và Cycle" trên bản đồ miền.
